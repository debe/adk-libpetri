# spec/

Reserved for cross-language specifications.

When porting adk-libpetri to a second language (TypeScript / Rust /
Python), shared semantic contracts (subnet shapes, boundary colour
catalog, structural invariants) belong here as language-neutral
specs — mirroring libpetri's `spec/` directory which carries the
CTPN semantic specification across Java / TS / Rust ports.

Currently empty — single-language (Java) implementation.
